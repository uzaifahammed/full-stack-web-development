# Group Project

Full-stack web application developed collaboratively as part of the Full Stack Web Development course.

## 🏗️ Architecture
- `client/`: Frontend application built with React.
- `server/`: Backend REST API built with Node.js, Express, and MongoDB.
- `screenshots/`: UI screenshots, demo recordings, and architectural diagrams.

## 🚀 Getting Started

### 1. Client Setup (React)
```bash
cd client
npm install
npm start
```

### 2. Server Setup (Node + Express + MongoDB)
```bash
cd server
npm install
npm run dev
```

## ⚙️ Environment Configuration
Make sure to create `.env` files in `server/` with the required MongoDB connection string and environment variables.
