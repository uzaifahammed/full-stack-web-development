# Assignment 2 - Individual Project

## 📌 Project Overview
This folder contains the source code, assets, and documentation for **Assignment 2 (Individual Project)**.

## 📁 Directory Structure
- `src/`
  - `index.html`: Entry HTML template.
  - `style.css`: Global styles.
  - `App.jsx`: Main React component.
  - `components/`: Modular React components.
  - `data.json`: Local dataset / mock data.
- `screenshots/`: Project screenshots and preview images.

## 🚀 Setup & Execution
Open `src/index.html` in your browser or run with a frontend development server (e.g., Vite or Create React App).
