## 2. Types of CSS

- **Files:** [`index.html`](./index.html) / [`2-types-of-css.html`](./2-types-of-css.html), [`style.css`](./style.css)
- **Aim:** To write an HTML program that demonstrates the three types of CSS — **Inline**, **Internal**, and **External** — used to style a web page.

### CSS Types Demonstrated:
1. **Inline CSS:** Applied directly using the `style` attribute on the element.
2. **Internal CSS:** Defined inside `<style>` tags within the `<head>` section.
3. **External CSS:** Defined in a separate stylesheet file (`style.css`) and linked via `<link rel="stylesheet">`.
