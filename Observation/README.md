## 📑 Topics & Experiments Documented

| Topic / Exp | Title | Description |
|---|---|---|
| **Module 1** | **Introduction to HTML & CSS** | Standard markup, tags, selectors, properties, HTML vs HTML5, CSS vs CSS3, MERN Stack vs Full Stack architecture. |
| **Module 2** | **Design a Static Webpage: Pomodoro Timer** | HTML structure & CSS styling for a responsive 25:00 Pomodoro countdown card with Start and Reset buttons. |
| **Module 3** | **JavaScript Arrays & Dynamic DOM Manipulation** | Iterating arrays, sum calculations, event listeners, dynamic background color, and heading modifications. |
| **Exp 5** | **Implement Modules in Node.js** | CommonJS (`module.exports` / `require`), ES Modules (`export` / `import`), and core built-in modules (`fs`, `http`, `path`). |
| **Exp 6** | **Mini Application using Node.js & Express** | Student Management System REST API (`GET`, `POST`, `DELETE /students`) with HTML frontend integration. |
| **Exp 7** | **Functional vs Class Components in React** | State management using React Hooks (`useState`) in Functional Components and `this.setState()` in Class Components. |
| **Exp 8** | **HTTP Methods using JSON Server** | Mock REST API testing `GET`, `POST`, `PUT`, `PATCH`, and `DELETE` requests using Fetch API and Postman. |
| **Exp 9** | **CRUD Operations with MongoDB & Mongoose** | Full database persistence with Express, Mongoose schemas, Postman testing, and MongoDB Compass verification. |
